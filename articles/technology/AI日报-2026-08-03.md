## 模型与 API

### OpenAI — GPT-5.6 Luna 降价 80%
OpenAI 在发布 GPT-5.6 仅三周后宣布降价。**Luna 降幅达 80%**，现价 $0.20/M input、$1.20/M output；Terra 降幅 20%，现价 $2/M input、$12/M output；旗舰版 Sol 不降价但 Fast 模式速度提升 2.5×。官方将成本下降归因于硬件路由优化、推理软件改进和更智能的 context caching 算法。
→ [OpenAI 原文](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6) · [VentureBeat 分析](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)

### OpenAI — GPT-Transcribe / GPT-Live-Transcribe
两款新转录模型上线 API。**GPT-Live-Transcribe** 面向低延迟实时场景；**GPT-Transcribe** 面向批量异步转录，在 Common Voice 22 语言测试中错误率从 40.4% 降至 19.3%（vs whisper-1），价格 $0.0045/min。当前不支持词级时间戳和说话人分离，仍需 whisper-1。
→ [OpenAI 开发者社区](https://community.openai.com/t/gpt-live-transcribe-and-gpt-transcribe-two-new-transcription-models-in-the-api/1388318) · [AlphaSignal](https://alphasignal.ai/news/openai-replaces-whisper-with-gpt-transcribe-slashing-errors-by-52)

### Anthropic — Claude Opus 5 发布
7 月 24 日发布，定价与 Opus 4.8 持平（$5/M input、$25/M output）。在 Frontier-Bench 和 GDPval-AA 等编程和知识评测上达到新 SOTA，接近 Fable 5 的前沿能力但价格减半。Fast 模式速度约为标准模式的 2.5×，现为 Claude Max 的默认模型。这是 Anthropic 在不到两个月内发布的第四款 Claude 5 系列模型。
→ [Anthropic 原文](https://www.anthropic.com/news/claude-opus-5) · [Fortune 报道](https://fortune.com/2026/07/24/anthropic-debuts-claude-opus-5-with-feature-that-lets-users-toggle-between-cost-and-capability/)

### DeepSeek — V4-Flash API 正式上线
7 月 31 日进入 public beta，模型更新为 deepseek-v4-flash-0731。284B 总参数、13B 激活参数的 MoE 架构，支持 1M token context。**原生支持 Responses API**（目前仅 V4-Flash 支持，V4-Pro 支持预计 8 月上线），针对 Codex 场景专门调优 post-training。
→ [TechNode](https://technode.com/2026/07/31/deepseek-puts-v4-flash-api-into-public-beta/) · [DeepSeek 官方博客](https://deepseek.ai/blog/deepseek-v4-flash-ga-agent-benchmarks)

### Moonshot — Kimi K3 开源
7 月 16 日发布、7 月 26 日提前开放权重。**2.7T 参数**，当前最大开源权重模型，1M token context。技术上采用 KDA + AttnRes、Stable LatentMoE (16/896)、MXFP4/MXFP8 训练，约 2.5× K2 的 scaling efficiency。性能自称接近 Fable 5，显著超过 Opus 4.8 和 GPT-5.6 Sol，但独立评测显示仍落后于 Fable 5 和 GPT-5.6 Sol。
→ [CNBC](https://www.cnbc.com/2026/07/17/moonshot-ai-kimi-k3-model-openai-anthropic-china.html) · [Caixin（开源报道）](https://www.caixinglobal.com/2026-07-29/moonshot-open-sources-kimi-k3-as-us-china-ai-tensions-intensify-102468927.html)

## 安全与研究

### Anthropic — Claude 发现密码学弱点
Claude Mythos Preview 在多 agent 环境中独立发现两个密码算法的攻击：1）**HAWK**（NIST 后量子候选签名方案）有效密钥强度减半；2）**轮次削减版 AES** 的新攻击，比此前最优攻击快 200–800×。整个 HAWK 攻击耗时约 60 小时、消耗 ~$10 万 API 费用。两项发现对现有生产系统均无直接影响（HAWK 尚未部署，AES 攻击针对削减版本）。
→ [Anthropic 研究原文](https://www.anthropic.com/research/discovering-cryptographic-weaknesses) · [The Next Web](https://thenextweb.com/news/anthropic-claude-mythos-cryptographic-attacks-hawk-aes)

### Microsoft — MAI-Cyber-1-Flash
微软发布首款网络安全专用 AI 模型，集成进 MDASH（多 agent 漏洞识别与修复系统）。与 GPT-5.4 组合在 CyberGym 基准上达到 **95.95%**，超过 OpenAI GPT-5.5 Cyber（85.6%）和 Anthropic Mythos 5（83%）。设计上负责处理 90% 的常规任务，仅将最难的 10% 交给 GPT-5.4，整体成本约为同类商业模型的一半。
→ [Microsoft AI 原文](https://microsoft.ai/news/introducing-mai-cyber-1-flash-inside-mdash/) · [SecurityWeek](https://www.securityweek.com/microsoft-unveils-mai-cyber-1-flash-its-first-cybersecurity-ai-model/)

### Microsoft — OpenForgeRL 开源
开源 RL 训练框架，支持在任意 harness 环境中端到端训练 agent。通过轻量代理记录 harness 的模型调用作为训练数据，配合 Kubernetes 编排实现每个 rollout 独立容器运行。在 ClawEval 达到 31.7 pass³，OSWorld-Verified 达到 37.7，WebVoyager 达到 72.3。
→ [arxiv 2607.21557](https://arxiv.org/abs/2607.21557)

## 推理优化

### 腾讯 — AngelSpec 开源
7 月 29 日开源，torch-native 的 speculative decoding 训练框架，支持 MTP 和 block-parallel DFlash 两类方案，一套 config-driven pipeline 覆盖 DFly、DFlash、DFlare、Eagle3、DSpark、MTP 六种 draft 架构。在混元 3（295B MoE，~21B 激活参数）TP=8 配置下，DFly-8 实现 **1.98–2.40× 加速**（并发 4 到 64 范围）。
→ [GitHub](https://github.com/Tencent/AngelSpec) · [MarkTechPost](https://www.marktechpost.com/2026/07/30/tencent-open-sources-angelspec-a-unified-training-framework-for-mtp-and-block-parallel-speculative-decoding-on-hy3-models/)
